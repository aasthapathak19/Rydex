# Rydex

A full-stack application built with Next.js and Socket.io.

## Ownership
This project is owned and maintained by [aasthapathak19](https://github.com/aasthapathak19).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
